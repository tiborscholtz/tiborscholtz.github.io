📁 Projects

Here are some of the tools and experiments I've built:

log2ip

log2ip is a cybersecurity-focused CLI tool written in Go that collects and analyzes IP address - related log entries from system log files. It is designed to help security engineers and system administrators quickly inspect authentication and SSH-related activity from multiple log sources in a simplified, readable format.

PHPTop

A lightweight PHP-based tool that interfaces with system-level monitoring commands and displays CPU and memory usage in a more accessible way.

PHPCronTab

A customizable handler that makes it easier to view, and search for scheduled tasks.

CVE-2026-24061

A lightweight Docker lab for experimenting with Telnet protocol negotiation, explained in the CVE-2026-24061 exploit, which contains automatic username injection using the NEW-ENVIRON option.

HoneypotFTP

A simulated FTP server built for experimentation and educational use. It allowed me to:

  • Explore lower-level protocol behavior
  • Work with socket programming
  • Test tools or scripts without exposing a real system

Guessr

Guessr is a small Go tool that reads the first few bytes of a file (its "magic bytes") and attempts to guess the file format with a confidence percentage. It's useful for quickly identifying file types without relying on file extensions.
